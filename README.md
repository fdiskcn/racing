# 弹珠比赛

第一视角 3D 弹珠竞速游戏。在自然环境赛道上操控弹珠冲向终点，共 5 个等级，难度逐步提升。

## 技术栈

- Vite + TypeScript
- Three.js（渲染）
- cannon-es（物理）

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可游玩。

生产构建：

```bash
npm run build
npm run preview
```

## 操作

| 按键 | 作用 |
|---|---|
| W / ↑ | 加速前进 |
| S / ↓ | 刹车 / 后退 |
| A D / ← → | 左右转向 |
| 空格 | 跳跃（第 3 关起） |
| Esc | 暂停 |

## 关卡

1. **青青牧场** — 开阔草地，熟悉操作  
2. **林间小径** — S 弯与控速  
3. **岩石山道** — 窄道障碍，需要跳跃  
4. **峡谷奔流** — 断崖跳跃与移动挡板  
5. **高峰风暴** — 窄脊、大落差与侧风  

进度保存在浏览器 `localStorage` 中。
